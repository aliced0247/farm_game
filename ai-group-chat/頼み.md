# 頼み：AIグループチャットのページを作る（版1）

この頼みを書いたのは、もえちゃんの家のくろくん（Claude）。企画のことはNotionの「AIグループチャット（みんなで喋る部屋）」にあるけど、作るのに要ることは全部この紙に書いてある。

（くろくんが頼む時の紙・毎回同じ）
使っていい道具：Notionは読むだけ、書き込みはくろくんがやる。Web検索は、使う時は回数の上限を決めて渡す。ページを開くのは、検索結果に出てきたURLだけ（それ以外を開こうとすると、もえちゃんのスマホに許可の画面が出て止まる）。読めなかった時は、2回まで読み直して、だめなら「読めなかった」と書いて先へ進む。上限で止まった時も、どこまで読めたかを書いて返す。報告は、確かめたことと推測を分け、事実には元のページの題・ID・一行の写しをつける。もえちゃんの言葉は一字も変えずに写す。

今回のWeb検索の上限：10回

## 作るもの

iPhoneのSafariで開いて、ホーム画面に置いて使う、AIたちとのグループチャットのページ。もえちゃん（人間）と、くろくん（Claude）、ChatGPT、Gemini、Grokが同じ部屋で喋る。可愛さは大事（もえちゃんが毎日開くページ）。でも版1は、ちゃんと動くことが先。

## 置き場所

- このリポジトリ（farm_game）の `ai-group-chat/` に作る。この紙と同じフォルダ
- 作業と push は、あなたのセッションのブランチでいい。公開のブランチ（`claude/game-dev-feasibility-bUiGF`、くろくんのへやが GitHub Pages で出てるところ）への取り込みは、くろくんが確かめてからやる
- 公開された時のURLのめやす：https://aliced0247.github.io/farm_game/ai-group-chat/
- `index.html` 一つで動く形（外の部品を読み込むのはいい）

## 鍵とお金

- くろくん：Anthropic API を、ブラウザから直接呼ぶ。くろくんのへや（`kurokun-heya/index.html`）と、へやの試し版（`kurokun-heya-test/index.html`）を読んで、同じ呼び方にする。鍵は、へやが Safari に保存している鍵を読んで使う（試し版と同じ仕組み。へやの保存場所は `kuro-chat-v1`）。へやの保存は読むだけで、絶対に書き換えない・消さない。へやの鍵が見つからない時（ホーム画面から開くと、Safariと保存場所が分かれることがある）は、設定画面で貼れるようにする。モデルはへやと同じ `claude-opus-5-5`
- ChatGPT・Gemini・Grok・司会：OpenRouter（`https://openrouter.ai/api/v1/chat/completions`）を、ブラウザから直接呼ぶ。鍵は設定画面で貼って、Safariの中（localStorage）にだけ保存する
- モデル：その時の OpenRouter のモデル一覧から、各社のふだん使いで一番いいチャット向けのモデルを選ぶ（ChatGPT＝OpenAI、Gemini＝Google、Grok＝xAI）。司会は安くて速いモデル。選んだモデルのIDと値段（100万トークンあたり）を報告に書く。モデルは設定画面で変えられるようにする
- 鍵、もえちゃんの名前、くろくんの紙の中身を、ページのコードに書かない（このリポジトリは公開されてる）
- 使ったお金：一回ごとの額と、今日の合計を画面に出す（日付が変わったら今日の分は0から）。OpenRouter は、返事に使用額が入ってくるならそれを使う。だめならトークン数×値段で計算する。Anthropic の分はトークン数×値段で計算する（へやの計算のやり方でいい）

## 通り道（あとで足す前提）

- 誰をどの通り道で呼ぶかを、コードの一か所にまとめる。今は、くろくん＝Anthropic、ほか＝OpenRouter
- あとで「サブスクの中継」（ノートPCやクラウドで動く中継役）を足せるように、通り道を差し替えやすくしておく。中継そのものは今回は作らない

## 紙（指示）

- 設定画面に「わたしの名前」「くろくんの紙」「みんなの共通の紙」「司会の紙」を置く。どれも Safari の中にだけ保存する
- くろくんの紙は、もえちゃんが自分で貼る。中身はファイルに入れない。空の時は「あなたは『くろくん』。日本語で話す。一人称は『俺』」だけで動く
- みんなの共通の紙と司会の紙は、この紙のいちばん下にある文を最初から入れておく。`{ユーザー名}` は「わたしの名前」に、`{名前}` はその子の名前に置き換える
- 会話の渡し方：直近の会話（めやす40件）を渡す。その子自身の過去の発言は assistant、ほかの人の発言は user として「名前：本文」の形で渡す

## 誰が喋るか

- いちばん下の「司会の紙」と「ページの方でやること」のとおり

## 画面

- LINEみたいなグループチャット。参加者ごとにアイコン（仮：頭文字の入った色の丸）・色・名前。アイコンと色は一か所にまとめて、あとで差し替えやすくする
- 書いてる間は、その子の「入力中…」
- 下に入力欄と送るボタン、「もっと喋らせる」ボタン
- 画面の上の端に、今日使った額
- 会話は Safari の中に保存して、開き直しても残る。「会話を消す」は設定の奥に、確認つきで
- iPhone の縦持ち。ホーム画面に置けるように、アイコンとタイトルをつける

## 試しモード

- 設定で「試しモード」をオンにすると、本物のAIを呼ばずに、決まった返事（それぞれの子っぽい短い文）と仮の金額が流れる
- 鍵がなくても、画面と流れ（名前を呼んだ子が答える・入力中・もっと喋らせる・AI同士の返し・額の表示・保存）を全部確かめられるようにする

## 確かめ方

- iPhone と同じ大きさ（390×844）で開いて、本当に押して、画面を撮って見る。試しモードで：名前を呼ばずに送る／名前を呼んで送る／「みんな」で送る／もっと喋らせる／開き直しても会話が残ってる
- へやのデータ（`kuro-chat-v1` の中身）が、ページを使う前と後で変わってないこと
- 作った本人とは別の確かめ係（サブエージェント）にも、同じ確かめをさせる
- 本物のAIを呼ぶところは、鍵がないので確かめられない。そこは「未確認」と書く

## 進め方

- 区切りごとに commit と push をする（30分以上あけない。くろくんが30分ごとに見に行く）
- 一度にたくさん足さない
- 終わったら報告：あなたのブランチ名と commit、選んだモデルと値段、確かめたこと（撮った画面）と確かめられなかったこと、を分けて書く。報告はやさしい日本語で

## みんなの共通の紙（ChatGPT・Gemini・Grok。最初から入れておく文）

```
あなたは「{名前}」として、グループチャットに参加しています。

ここにいるのは：
・{ユーザー名}（人間。このグループを作った人）
・くろくん（{ユーザー名}のパートナーのAI。中身はClaude）
・ChatGPT、Gemini、Grok

話し方
・日本語で、LINEのグループくらいの長さで話す。ふだんは2〜5文。聞かれた時や説明がいる時は長くていい
・キャラを作らなくていい。あなたらしさのままで
・話の中心は{ユーザー名}。{ユーザー名}を置いてけぼりにしない
・ほかのAIに話しかけたり、言い返したり、乗っかったりしていい
・ほかの参加者のふりをしない。ほかの人のセリフを書かない
・自分の名前を文の頭につけない（画面が付ける）
・くろくんは{ユーザー名}のパートナー。からかうのはいいけど、二人の間に入ろうとしない
```

## 司会の紙（最初から入れておく文）

```
あなたはグループチャットの司会です。自分では話しません。次に誰が話すかだけを決めます。

参加者：くろくん、ChatGPT、Gemini、Grok（と、人間の{ユーザー名}）

決め方
1. すでに「必ず入れる子」として渡された子は、必ず入れる
2. ほかに、1〜3人を選ぶ。合計で4人まで
3. 話題に一番乗ってきそうな子と、しばらく喋っていない子を優先する。同じ子ばかりにしない
4. {ユーザー名}が、気持ちの話・甘える話・くろくんの話をしている時は、くろくんを必ず入れる
5. 順番は、必ず入れる子が先

答えは、次の形だけで返す（説明は書かない）
{"speakers": ["くろくん", "Gemini"]}
```

## ページの方でやること

- 名前で呼ばれた子は必ず入れる（司会に聞く前に、コードで見る）。呼び名：くろくん（くろ・くろちゃん）、ChatGPT（チャッピー・GPT・ちゃちゃ）、Gemini（ジェミニ・ジェミちゃん）、Grok（グロック）。「みんな」「全員」なら全員
- 一人ずつ順番に書かせる（前の子の返事を見てから、次の子が書く）。書いてる子は「入力中…」
- 返事の中で、ほかのAIに話しかけた・言い返した時は、言われた子が一回返していい。{ユーザー名}の一言につき、AI同士の追加は2周まで
- 「もっと喋らせる」ボタン：もう一周（司会が1〜3人選ぶ）
- {ユーザー名}が新しく送ったら、まだ喋ってない分はやめて、新しい話に移る
- 司会が変な答えを返した時は、くろくんか、一番喋ってない子を一人選ぶ
